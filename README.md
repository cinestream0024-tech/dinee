# DINEE Platform

Infrastructure privée du réseau Le DINEE à Kinshasa : Laravel API et une seule application React.

- [Démarrer le développement](docs/development.md)
- [Périmètre MVP et phases](docs/product-mvp.md)

Le frontend conserve les composants du template TailAdmin existant et sa [licence MIT](LICENSE.md).
Les démonstrations sont conservées comme références mais ne sont plus routées dans l'application.
Aucune inscription publique, aucun envoi WhatsApp automatique et aucun annuaire public.

Les fonctionnalités sont livrées phase par phase avec validation explicite.
